# Página da cliente

Página estática (HTML + CSS + JS), sem build. Abra o `index.html` no navegador.

## O que editar
- **Textos entre MAIÚSCULAS** no `index.html`: `NOME`, `CIDADE`, `XX` (idade), `1,XX` (altura), textos de apresentação e informações.
- **WhatsApp**: troque `55DDDNUMERO` (2 lugares) pelo número só com dígitos, ex.: `5581999999999`.
- **Instagram**: troque `USUARIO`.
- **Fotos**: coloque na pasta `fotos/` com os nomes `01.jpg` até `12.jpg`. As que não existirem somem da galeria sozinhas.
  A foto principal (topo) é `fotos/04.jpg` e a do "Sobre" é `fotos/05.jpg`.
- **Cores**: no começo do `style.css` (`--accent` vermelho, `--accent-2` dourado).

## Publicar
Pode subir a pasta inteira em Netlify, Vercel ou GitHub Pages.
